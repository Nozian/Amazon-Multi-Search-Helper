Amazon Toolkit v1.7 — 日本語IME入力の修正
========================================

【v1.7で直した点】
- ほしい物リストの検索入力で、日本語変換中に入力欄を再作成しないよう修正。
- ひらがな入力中も検索結果を更新し、変換を確定したら即時に再検索。
- 検索欄への入力フォーカスと変換候補ウィンドウを保持。
- 中古価格や商品説明がバックグラウンドで更新されても、日本語入力を中断しない。
- 商品タグ入力時も、検索結果の作り直しが変換を中断しないよう保護。
- AI意味検索の入力欄でも、変換確定のEnterキーを「検索実行」と誤認しない。
- 商品説明・AI検索、中古価格の並列照合、CSV出力、固定列数、他サイト検索は引き継ぐ。

【更新】
旧Amazon-Toolkitフォルダーのファイルを新ZIPの中身で置き換え、
chrome://extensions/ の再読み込み、その後Amazonほしい物リストのページを更新。
古い同種拡張は無効化し、重複動作を避けてください。

【検証】
ローカルテストページでIMEのcompositionstart/input/compositionendを模擬し、
変換中のDOM維持・フォーカス保持・漢字確定後の即時絞り込みを確認済み。
実Amazonページへのログインを伴う最終確認は未実施です。

Amazon Toolkit v1.6 — 商品説明＋AI検索
Amazon Toolkit v1.5.0 — 同時照合とリスト内検索
================================================

【改善点】
- 中古価格確認ボタンを廃止。ほしい物リストを開くと読み込み済みの商品から自動で中古出品情報を確認します。
- Amazonの中古出品一覧→出品パネル→商品詳細ページの順に照合を試みます。
- 同じ中古出品カードで表示された価格と送料だけ合算します。出品者の異なる価格と送料は合算しません。
- 送料が判明しなければ中古価格だけ表示して合計は出しません。
- 出品価格が見つからない場合の表示を「表示から価格を確認できず」へ変更。
- Amazon側の認証・Captcha・403・429・503を検出したら自動通信を一時停止します。
- 取得済みの情報はChrome内にキャッシュします。成功12時間・取得できず2時間・アクセス制限20分程度、再確認を控えます。
- 商品ごとにボタンを押す必要はありません。Amazonが表示していない情報の取得は保証できません。
- ポップアップに「中古価格と送料を自動確認」オン・オフを追加（初期オン）。

【従来機能】
Google/DuckDuckGo検索タブ→Amazon変換、元に戻す／他書店・図書館への横断検索／
ほしい物リストの1〜10列固定グリッド／タグ・カラー／CSV・AI向けテキスト／複数リストの収集履歴。

【仕組みと注意】
この拡張はAmazon公式価格APIではありません。Amazonがユーザーに返すHTML上の表示のみを読みます。
一部の商品、出品者、送り先で価格・送料が非表示・動的読み込み・購入画面で確定の場合、表示できません。
「Amazon中古出品一覧で読めた例」であり全出品の最安値保証ではありません。
購入直前はAmazonの商品ページや出品一覧で価格・配送料・状態・配送先を確かめてください。
送信先はamazon.co.jpで、独自の外部サーバーには送信しません。
大量通信による制限を抑えるため、照合は初期2商品（設定で1〜3）同時、各商品の照合開始は1.1秒以上離します。ブラウザタブ非表示では新規照合を一時停止します。
認証制限が出た場合は迂回せず停止します。

【更新】
旧Amazon Toolkitのフォルダーをv1.6の内容で置き換え、chrome://extensions/ で再読み込み、
Amazonのほしい物リストページを更新してください。
旧版のほしい物リスト拡張があれば重複しないよう無効化してください。
保存済みのリスト情報とタグは従来のキーを引き継ぎます。

【確認状況】
ローカルに作成した中古出品HTMLを使用して解析と自動処理をテストしています。
Amazonの実アカウントでの検証は未実施です。Amazonの表示形式により取得できない場合があります。

■ v1.5 の変更点
- 中古商品価格の照合を複数の商品で並行して行います。標準2件、設定で1〜3件。
- 急激なアクセスを避けるため照合の開始間隔を1.1秒以上としています。
- Amazonのアクセス制限・確認画面を検知したら、新規照合を20分停止します。
- ほしい物リストの上部に検索欄を追加しました。商品名・タグ・価格・中古状態を絞り込めます。
- 「中古価格あり」「送料込み合計あり」「中古価格未取得」「タグ付き」でフィルターできます。
- 検索は現在のリストでChrome内に収集・保存された商品が対象です。Amazonサーバー上の未取得商品は検索できません。
- 一致商品が2000件を超える場合は、ブラウザの動作を守るため先頭2000件を表示します。
- Amazonのページ構成により中古価格・送料が取得できない場合があり、表示結果は購入時の確定価格ではありません。

【更新方法】以前のAmazon-Toolkitフォルダーの中身を置き換え、chrome://extensions/ で再読み込み。Amazonのほしい物リストも再読み込みします。


新機能（v1.6）:
・Amazonの商品詳細ページの説明文を収集・ローカルに保存。ほしい物リストからは「📖 説明文をまとめて取得（30件）」で順次追加取得。
・通常検索は商品名・タグ・商品説明のキーワード部分一致（APIキー不要）。
・AI意味検索はGemini APIキーを設定した場合のみ使用可能。自然文で収集済み商品を検索し、AIの選定理由を表示。
・外部へ送られる商品情報：商品名、保存済みの説明文、自分のタグ、検索質問。AIで意味検索ボタンを押したときだけ送信します。
・Gemini APIキーはchrome.storage.sessionへ一時保存され、Chrome終了時に消えます（Google APIは個別の契約が必要で課金されることがあります）。
・AI検索は最大500商品、40件ずつ送信。収集できていない商品は対象外。Amazonの全商品説明を取得できるとは限りません。
・Amazonのアクセス制限を受けた場合、説明文の取得を停止します。サーバーを迂回する処理はありません。

【AIモデル】ポップアップからGemini 2.5 Flash / Gemini 3.5 Flashを選べます。Google側でモデル提供状況や利用条件が変わることがあります。

【導入の流れ】ZIPを展開してAmazon-Toolkitフォルダーをchrome://extensions/から「パッケージ化されていない拡張機能」として読み込み。旧版は無効化し、Amazonのページを再読込。
【AI検索の準備】Google AI StudioでGemini APIキーを作成→拡張アイコン内のAI意味検索欄へ貼り付けて「AIキーを一時設定」→ほしい物リストの検索欄からAIで意味検索。キーを保存しなくても商品説明のキーワード検索、AIへのテキストコピーは利用可。ChatGPT有料プランの支払いはGemini APIの利用契約とは別です。
【説明文】既にAmazonに読み込まれた商品を拡張が保存している場合でも、未配信・未収集の商品の詳細情報はAI検索対象に入りません。閲覧時に説明文を収集、またはリストから30件ずつまとめて収集。Amazonの仕様変更で取得できない場合は不明として扱います。


[v1.8] 全件収集・商品説明文の収集・中古価格の照合中は、ページ右下に固定表示される「収集を停止」から即座に新規作業を停止し、進行中の価格・説明取得リクエストもキャンセルできます。保存済みのデータは消えません。停止後は右下の「中古照合を再開」で自動照合を再開できます。
