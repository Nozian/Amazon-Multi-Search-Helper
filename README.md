# Amazon Toolkit v1.8.0

Latest unified Chrome extension source (2026-10-24). Includes Amazon search, wishlist organization, book comparisons, description-based searches and always-available stop controls.

## Install
1. On this branch, choose **Code → Download ZIP**.
2. Extract the downloaded archive.
3. Open `chrome://extensions/` and turn on **Developer mode**.
4. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.

See `README.txt` for feature details. To preserve Chrome extension storage, update the original extension folder and reload it when possible; back up important data first.

The source in this release branch is independently versioned; the original `main` branch remains unchanged.

**Version:** 1.8.0. **Testing:** browser simulation, not guaranteed on live sites.
